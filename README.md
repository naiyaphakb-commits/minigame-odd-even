# Minigame Odd–Even — HTML prototype

ขึ้น UI จาก Figma `minigame_odd-even`
([design](https://www.figma.com/design/f6SXA17EjH53R5sNtDfgNm/minigame_odd-even?node-id=214-26894) ·
[component](https://www.figma.com/design/f6SXA17EjH53R5sNtDfgNm/minigame_odd-even?node-id=113-8645))
เป็น HTML/CSS/JS ล้วน ไม่มี build step

## รัน

```bash
python3 serve.py
```

แล้วเปิด <http://localhost:4173>

> ใช้ `serve.py` แทน `python3 -m http.server` เพราะมันส่ง `Cache-Control: no-store`
> แก้โค้ดแล้วรีเฟรชเห็นผลทันที ไม่ติดไฟล์เก่าในแคช (ไฟล์ css/js ยังมี `?v=` กำกับไว้อีกชั้น) (ต้องเสิร์ฟผ่าน http เพราะมีวิดีโอ/ภาพเป็นไฟล์แยก)
ออกแบบไว้ที่ความกว้าง **430px (iPhone 16 Plus)** ตามเฟรมใน Figma — ยังไม่ทำ desktop

## Responsive (มือถือ)

`.app` กว้าง 100% แต่ไม่เกิน **430px** — ที่ 430 ทุกชิ้นเท่าเฟรม Figma เป๊ะ
(frame 398 · fair/stage/tab bet/bar chip/board 366 · track 270 · การ์ด 177 · ไข่ 111)
จอที่แคบกว่านั้นทุกอย่างย่อตามสัดส่วน ไม่มีส่วนไหนโดนตัด ทดสอบถึง **320px**

| ส่วน | เดิม | ตอนนี้ |
|---|---|---|
| `.frame` / `.history` | 398px | `calc(100% - 32px)` สูงสุด 398 |
| `.tabbet` | 398px + padding 16 | `100%` padding บน-ล่างอย่างเดียว (กรอบแม่มี padding แล้ว) |
| `.fair` / `.barchip` / `.board` / `.mine` / `.bethist` | 366px | `100%` |
| `.stage` | 366×310 | `100%` + `aspect-ratio:366/310` |
| `.stage__pop` | 366×366 margin −183 | `100%` + `aspect-ratio:1` margin `-50%` |
| `.barchip__track` | 270px | `flex:1 1 0` (ALL IN / MAX คงขนาดเดิม) |
| `.loadbar` | 300px | `min(300px,78vw)` |

**ไข่ไม่หลุดรัง** — พิกัดไข่เปลี่ยนจาก px เป็น % ของเวที คิดจากค่าที่วัดรังไว้ตอน 366×310
`--egg-x0:3.005%` `--egg-x1:35.246%` `--egg-x2:67.486%` `--egg-y:55.161%` · ไข่กว้าง `30.328%` + `aspect-ratio:1`
เงาใต้ไข่และแสงวาบตอนแตกก็คิดเป็น % ของตัวไข่ ทุกอย่างจึงย่อพร้อมกันทั้งชุด

## ส่งออกเป็นไฟล์เดียว

```bash
python3 build-single.py
```

ได้ `dist/odd-even.html` (~34MB) รวม CSS · JS · รูป · เสียง · ฟอนต์ ไว้ในไฟล์เดียวเป็น data URI
ดับเบิลคลิกเปิดได้เลย ไม่ต้องรันเซิร์ฟเวอร์ ไม่ต้องต่อเน็ต
ตัว `dist/` ไม่ได้ commit ขึ้น git (สร้างใหม่ได้ตลอด)

## Token ที่ใช้

ดึงจาก Figma variables ตรง ๆ ไม่ได้ตั้งค่าเอง — `color-02/*`, `typography/*`, `space/*`, `radius/*`
อยู่ใน `:root` ของ `css/styles.css` ฟอนต์ `IBM Plex Sans Thai` (10/12/14/16/20) โหลดจาก Google Fonts

## Flow / timing

| สเตท | พฤติกรรม |
|---|---|
| 1. loading | แถบดาวน์โหลดตาม component `bar loading` — "Loading..." ซ้าย, % สีทองขวา, แถบไล่สีแดง→ทอง→ครีม, มาสคอต 24px วิ่งตามหัวแถบ · ครบแล้วขึ้นปุ่ม **เริ่มเกม** |
| 2. เริ่มต้น | ยกเลิก / แทงซ้ำ / ยืนยัน = disable |
| 3. เลือกฝั่ง | วางชิพแล้ว → ยกเลิก + ยืนยัน active, แทงซ้ำ disable, การ์ดขึ้นป้าย “คุณเลือก” + ชิพที่วาง · ป้ายบนเวทีบอกฝั่งด้วย **เดิมพันคู่ : 50.00** |
| 4. รอประมวลผล | กดยืนยัน → ตัดเครดิต → อนิเมชั่น **5.5 วิ** → เฉลยเลข |
| ออกผล | ป้ายบนเวทีขึ้นผลรวมสี `#fafafa` · popup **YOU WIN / YOU LOSE** ค้าง **4.5 วิ** แล้วหาย เหลือปุ่ม **เริ่มเดิมพันรอบใหม่** |
| 5. แทงซ้ำ | กดเริ่มรอบใหม่ → ปุ่ม **แทงซ้ำ** active (คืนค่าเดิมพันรอบก่อน) |
| 6. เปลี่ยนฝั่ง | แตะอีกฝั่งขณะมีเดิมพัน → เตือน “แทงได้ฝั่งเดียว · กดยกเลิกถ้าจะเปลี่ยนฝั่ง” **1.5 วิ** |
| 7. เครดิตไม่พอ | เตือน “ยอดเงินของคุณไม่พอ” **1.5 วิ** และวางเดิมพันไม่ได้ |
| 8. ตั้งค่าเสียง | เปิดจากไอคอนลำโพงบน header · ปิดด้วยกากบาทหรือแตะนอกกรอบ |
| 9. กติกา | เปิดจากไอคอน `?` · ปิดด้วยปุ่มเข้าใจแล้วหรือแตะนอกกรอบ |
| 10. เค้าไพ่ / ประวัติ | ทั้งสองแท็บเริ่มจาก component **empty state** แล้วเปลี่ยนเป็นตาราง/รายการเมื่อมีข้อมูลรอบแรก · เลื่อนแนวนอนได้ เส้นตารางลากต่อจนสุดทุกคอลัมน์ · ประวัติของฉันเริ่มจากว่างแล้วเพิ่มเมื่อเล่นจริง |

ค่าเวลาทั้งหมดอยู่หัวไฟล์ `js/app.js` (`ROLL_MS`, `RESULT_MS`, `TOAST_MS`, `LOAD_MS`)
อัตราจ่าย 1.95 เท่า · ขั้นต่ำ ฿10 · **ไข่ 3 ใบสุ่มใบละ 0–9 แล้วนำมาบวกกัน** (ผลรวม 0–27)

## Component: Fairness Panel

แตะหัวพาเนลเพื่อกาง (state=expended) จะเห็น **Early Announced Hash** ที่ประกาศไว้ก่อนเดิมพัน
พร้อมปุ่มคัดลอกทั้งสองช่อง · สถานะเปลี่ยนจาก "รอออกผล" (เหลือง) เป็น "ออกผลแล้ว" (เขียว `#7fd382`) เมื่อไข่แตก
ตอนรอผล Private Key จะปิดไว้เหลือ 3 ตัวท้าย แล้วเปิดเต็มเมื่อออกผล — ผู้เล่นเอาไปเทียบแฮชเองได้

รูปแบบโค้ด (47 ตัวอักษร พอดีช่อง 318px ที่ฟอนต์ 10px บรรทัดเดียว)

```
715648b66020cb945ab4611-O-b359ceed5d4b648501ZXC
└──── 23 ตัว ────┘ └┬┘ └──── 18 ตัว ────┘└3 ตัวท้ายพิมพ์ใหญ่┘
                เครื่องหมายผล
```

**`-O-` เมื่อออกคู่ · `-E-` เมื่อออกคี่** — แสดงเป็น**สีฟ้า `#0EA5E9` ตัวหนา** (`.fair__mark`) ให้ต่างจากตัวโค้ดสีเทา
ปรับได้ที่ `SEED_LEN` / `SEED_SPLIT` / `RES_MARK` ใน `js/app.js`
รหัสรอบในแถวประวัติใช้รูปแบบเดียวกัน

ขนาดตาม component: ปิด 366×62 · กาง 366×122 (62 + ส่วนที่กางออก 60)
โค้ดใช้ `IBM Plex Mono` 10/15 สี `#A3A3A3` และ **ไม่ตัดด้วย …**
ที่ 430px (เฟรมออกแบบ) โค้ด 47 ตัวอยู่บรรทัดเดียวพอดีที่ฟอนต์ 10px
จอแคบกว่านั้นย่อฟอนต์อัตโนมัติ (< 430px = 9px · < 390px = 8px) เพื่อคงให้อ่านได้ครบในบรรทัดเดียว
`state=success` (ออกผลแล้ว) เพิ่มคลาส `.is-done` ที่เปลี่ยนเงาเป็น `0 3px 6px rgba(0,0,0,.25)`
ส่วนพื้นกับขอบใช้ `#2C2D30` เท่าเดิมอยู่แล้ว จึงไม่ต้องเปลี่ยน

ใส่ไฟล์เพิ่มได้ที่ตาราง `FILES` หัวไฟล์ `js/sfx.js` (คีย์ = จุดที่ใช้)

| `place` | วางชิพลงการ์ดเดิมพัน | สังเคราะห์ |
| `cancel` | กดยกเลิกเดิมพัน | สังเคราะห์ |
| `confirm` | กดยืนยันเดิมพัน | สังเคราะห์ |
| `hop` | ไข่เด้งแต่ละครั้ง | สังเคราะห์ |
| `crack` | ไข่แตก | สังเคราะห์ |
| `win` / `lose` | popup ผลแพ้-ชนะ | สังเคราะห์ |

### เสียงพากย์ (`assets/audio/voice/`)

พากย์ไทยจากไฟล์ที่ได้รับ ตัดจากไฟล์เดียวเป็น 10 ประโยค (ต้นฉบับเก็บที่ `assets/audio/clips/_source-full.wav`)
เล่นซ้อนบนเสียงเอฟเฟกต์และเพลงพื้นหลัง ใช้สวิตช์ "เสียงเอฟเฟกต์" ร่วมกัน · พูดทับกันไม่ได้ (ประโยคใหม่ตัดประโยคเดิม)

| คีย์ | จำนวนไฟล์ | เล่นตอน |
|---|---|---|
| `roundStart` | 2 | เปิดรอบเดิมพันใหม่ (รวมตอนเข้าเกมครั้งแรก) |
| `hurry` | 2 | เหลือ 10 วินาที และยังไม่ได้วางเดิมพัน |
| `placeEven` / `placeOdd` | 1 / 1 | วางชิพฝั่งคู่ / คี่ — พูดทุกครั้งที่วาง เลือกประโยคตามฝั่ง |
| `confirm` | 6 | กดยืนยันเดิมพัน |
| `win` | 6 | ชนะ |
| `winStreak` | 2 | **ชนะติดต่อกันครบ 3 ครั้ง** (แทนเสียงชนะปกติ) |
| `lose` | 9 | แพ้ |
| `noBet` | 1 | หมดเวลาแบบไม่ได้วางเดิมพัน |
| `lowCredit` | 1 | ยอดเงินไม่พอ |

คีย์ที่มีหลายไฟล์ใช้วิธี **จับสลากในถุง** — สุ่มลำดับใหม่ทุกครั้งที่หมดถุง
จึงได้ยินครบทุกประโยคก่อนจะวนซ้ำ และไม่มีประโยคเดิมติดกันสองครั้ง (เช่น แพ้ 9 ประโยค = ไม่ซ้ำเลย 9 รอบ) · ไฟล์มาจาก 2 ชุดที่ได้รับ (ต้นฉบับอยู่ที่
`assets/audio/clips/_source-full.wav` และ `assets/audio/clips-02/_source-full.wav`)

เพิ่ม/เปลี่ยนไฟล์ได้ที่ตาราง `VOICE` หัวไฟล์ `js/sfx.js` · ใส่หลายไฟล์ในคีย์เดียว = สุ่มสลับกันเอง
ตัวนับชนะติดกันอยู่ที่ `state.winStreak` ใน `js/app.js` (แพ้เมื่อไหร่รีเซ็ตเป็น 0)

**เสียงเอฟเฟกต์**

| เสียง | ประกอบด้วย |
|---|---|
| เลือกชิพ | เสียงชิพกระทบ (noise สั้น) + ติ๊งใส |
| วางเดิมพัน | ตุ้บเบา + ป๊อกสองโน้ตเด้งขึ้น |
| ยืนยัน | อาร์เพจจิโอ C-E-G-C ไล่ขึ้น + ประกาย |
| ไข่เด้ง | บ๊อยง์การ์ตูน (กวาดเสียง 150→520 Hz + vibrato) ยิงตามจังหวะเด้งจริงที่เร่งขึ้น |
| **ไข่สั่น** | เสียงสั่นต่อเนื่อง — เบสกวาด 48→96 Hz + tremolo รัว 14→30 ครั้ง/วิ + เศษหินกระทบถี่ขึ้น ดังขึ้นเรื่อย ๆ จนถึงจุดแตก |
| **ไข่แตก** | ตุ้บหนัก 140 Hz + เปลือกแตก + เศษกระจาย + ประกายทอง 3 โน้ต |
| ชนะ | แฟนแฟร์ 6 โน้ต C-E-G-C-E-G + ประกายรัว + เสียงค้างท้าย |
| แพ้ | ว้าว ๆ แบบการ์ตูน 3 โน้ตไหลลง (ไม่หดหู่) |
| **เหรียญเข้ากระเป๋า** | ติ๊งโลหะใส (โน้ต + ฮาร์มอนิก 2.01 เท่า + เสียงเหรียญกระทบ) ไล่เพนทาโทนิก C-E-G-A-C-E สูงขึ้นทีละใบ |
| **เหรียญร่วงตอนแพ้** | เสียงเหรียญกระทบทื่อ ๆ + โน้ตไหลต่ำลง 420→190 Hz + ตุ้บเบา |
| **เหรียญใบสุดท้าย** | ปิดท้ายแบบเครื่องคิดเงิน G-C-E ค้างยาว + ประกาย + ตุ้บเบา |

**เสียงพื้นหลัง** — ลูปงานวัด/เครื่องเล่น 142 BPM ยาว 4 ห้อง (32 เขบ็ต) คอร์ด C · F · G · C

- **อุ่ม-ป๊ะ** — เบสลงจังหวะ 1 กับ 3 สลับคอร์ดสั้น ๆ จังหวะ 2 กับ 4 แบบวงดนตรีงานวัด
- **เมโลดี้ออร์แกน** — square + triangle ซ้อนกันเพี้ยนเล็กน้อย (±7–9 cent) ให้ฟังหนาแบบคาลิโอปี
- **กลอง** — คิกจังหวะ 1/3 · สแนร์เบาจังหวะ 2/4 · ไฮแฮตทุกเขบ็ตคี่ · ฉาบปิดท้ายทุกลูป
- ใส่สวิง 14% ในเขบ็ตคี่ให้เด้ง

ปรับได้ที่ `BPM`, `ROOT`, `STAB`, `MEL` ใน `js/sfx.js`

เปิด-ปิดแยกกันได้ที่หน้าตั้งค่าเสียง · เบราว์เซอร์เริ่มเล่นเสียงได้หลังผู้ใช้แตะครั้งแรก จึงเริ่มตอนกด "เริ่มเกม"

## นับถอยหลังเวลาเดิมพัน

ทุกรอบมีเวลาเดิมพัน **30 วินาที** แสดงเป็นป้ายมุมขวาบนของเวที (`.timer`)
เหลือ ≤ 10 วิ ป้ายเปลี่ยนเป็นสีแดงและเต้นเตือน

| หมดเวลาแล้ว | ผลที่เกิด |
|---|---|
| วางเดิมพันไว้แล้ว | ยืนยันให้อัตโนมัติ แล้วเข้าสู่ช่วงออกผล (ป้ายซ่อนระหว่างออกผล) |

## Component: bar chip

366×60 · gap 4 · `[ALL IN 44px] [track 270×60 radius 999] [MAX 44px]`
ในรางเลื่อนแนวนอนได้ ชิพที่เลือกจะเลื่อนมาอยู่กึ่งกลาง track เสมอ
ลูกศร `‹` `›` เป็นแถบ `rgba(23,23,23,.6)` กว้าง 30px ทับขอบซ้าย-ขวาของราง

> ไฟล์ `a-*.png` เป็นภาพ 72px ที่มีตัวชิพ 50px อยู่กลาง (69% ของภาพ) เพราะ Figma เผื่อขอบไว้ให้เงา
> จึงต้องแสดงที่ `width:144%` พร้อม `margin:-22%` ตัวชิพถึงจะเต็มกรอบพอดี

> export ต้องใช้ `contentsOnly` เสมอ ไม่งั้นพื้นหลัง canvas สีเทา `#323232` จะติดมากับไฟล์

## Component: bet choice

การ์ดเดิมพันทำตาม component set `bet choice` ครบ 6 state (177×60, radius 8)

| state | คลาส | หน้าตา |
|---|---|---|
| default | — | คู่ = เขียว `#5AAF20 → #357738` ไม่มีเส้นขอบ · คี่ = แดง `#F43220 → #8E281E` ขอบ `#A12828` |
| hover | `:hover` | ทับด้วย `rgba(255,255,255,.1)` |
| active | `.is-picked` | ขอบ `#357738` (คู่) / `#A12828` (คี่) + mark “คุณเลือก” มุมขวาบน + กองชิพ 32px |
| bet win | `.is-win` | ขอบ `#FAFAFA` · mark พื้นขาว ตัวอักษร `#4EAF51` |
| bet lose | `.is-lose` | เหมือน active + `opacity .6` |
| result | `.is-result` | ขอบ `#FAFAFA` (ฝั่งที่ออกผลแต่ผู้เล่นไม่ได้แทง) |

mark = 54×18, padding 2/8, radius `0 8px 0 8px`, shadow `0 1px 3.8px rgba(0,0,0,.35)`,
ตัวอักษร Bold 10/14 · ชิพ 32×32 วางชิดขวา top 20px พร้อม drop-shadow ตามสเปก

**กองชิพ** — วางชิพหลายใบหรือสลับชิพระหว่างรอบ จะซ้อนกันแนวนอน เหลื่อมใบละ 12px
ใบล่าสุดอยู่บนสุดขวาสุดพร้อมอนิเมชั่นหล่นลงมา · แสดงสูงสุด 5 ใบ เกินนั้นขึ้นป้าย `+N` ทางซ้าย
กดยกเลิกล้างกอง · กดแทงซ้ำคืนกองของรอบก่อนทั้งกอง

**ชิพไหลเข้า-ไหลออก** — วางเดิมพันแล้วชิพจะไหลจากรางเลื่อน โค้งขึ้นกลางทาง หมุน 1 รอบ แล้วลงบนการ์ด (340 ms)
กดยกเลิกชิพทั้งกองไหลย้อนกลับเข้าราง หมุนย้อนทาง ไล่ทีละใบห่าง 70 ms จากใบบนสุดลงไป
ทำด้วยตัวโคลน `.chip-fly` ลอยบน `body` (`position:fixed`) ตัวจริงบนการ์ดซ่อนไว้จนไหลถึง
ปรับความเร็วที่ `FLY_MS` ใน `js/app.js`

**เหรียญรางวัลไหลเข้ายอดเงิน** — ตอนชนะ ยอดเงินบน header จะ "พักไว้" ยังไม่บวกรางวัลระหว่าง popup YOU WIN ค้างอยู่
พอ popup ปิด เหรียญ 12 ใบยิงจากกลาง popup ไล่ทีละใบ (ห่าง 45 ms) โค้งหมุนไปรวมที่ไอคอนยอดเงิน
ทุกใบที่ถึงปลายทาง ยอดเงินไต่ขึ้นตามสัดส่วนพร้อมเด้งรับ + **เสียงเหรียญเข้ากระเป๋า** จนครบเท่ารางวัลพอดี
**แพ้ — เหรียญร่วงจากยอดเงิน** — พอ popup YOU LOSE ปิด เหรียญ 8 ใบร่วงออกจากไอคอนยอดเงินบน header
กระจายซ้ายขวา หมุนตกลงข้างล่าง แล้วจางหาย ไล่ทีละใบห่าง 70 ms พร้อมเสียงเหรียญกระทบ
ปรับที่ `DROP_N` / `DROP_MS` / `DROP_GAP` · เป็นอนิเมชั่นล้วน ไม่แตะยอดเงิน (หักไปตั้งแต่กดยืนยันแล้ว)

ปรับที่ `COIN_N` / `COIN_MS` / `COIN_GAP` · ถ้ากดเริ่มรอบใหม่ระหว่างเหรียญยังไหล `coinRun` จะตัดรอบเก่าทิ้ง ยอดไม่เพี้ยน
