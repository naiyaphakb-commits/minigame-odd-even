    การตั้งค่าเสียง

    กติกาการเล่น

    เกมคู่คี่ผู้เล่นเดิมพันว่าผลรวมตัวเลขจากไข่ทั้ง 3 ใบจะออกเป็น เลขคู่ หรือ เลขคี่ เกมนี้เล่นคนเดียว ไม่มีการปะทะกับผู้เล่นอื่น ทุกรอบจบภายในไม่กี่วินาที และทุกผลลัพธ์สามารถตรวจสอบย้อนหลังได้ว่าไม่มีการโกงเกิดขึ้น

    วิธีเล่น

    1. เลือกจำนวนเงินเดิมพันจากชิพที่กำหนด (10 / 20 / 50 / 100 / 500 / ALL IN) หรือกำหนดเองในช่วงที่อนุญาต
    2. แตะเลือกฝั่งที่ต้องการทาย — คู่ หรือ คี่
    3. กด “ยืนยันเดิมพัน” เพื่อวางเดิมพัน — ณ จุดนี้ระบบจะตัดเครดิตทันที และเปิดเผยผลในเสี้ยววินาทีถัดไป
    4. ไข่ทั้ง 3 ใบจะแตกออกพร้อมกัน แต่ละใบแสดงตัวเลข 0–9
    5. นำตัวเลขทั้ง 3 ใบมาบวกกัน ได้ผลรวมในช่วง 0–99
    6. หากผลรวมตรงกับฝั่งที่ทายไว้ ถือว่า ชนะ และได้รับเงินคืนตามอัตราจ่าย ถือว่า แพ้ และเสียเงินเดิมพันที่วางไป

    อัตราจ่าย

    โอกาสออกเลขคู่และเลขคี่เท่ากันพอดีที่ 50% ต่อ 50% ไม่มีฝั่งใดได้เปรียบ ทายถูกได้รับเงินคืน 1.95 เท่า ของยอดเงินเดิมพัน (เช่น เดิมพัน 100 บาท ชนะรับ 195 บาท)

    เค้าไพ่และประวัติการเล่น

    เค้าไพ่ แสดงผลลัพธ์ (คู่/คี่) ของรอบก่อนหน้าเรียงตามลำดับ ใช้เป็นข้อมูลอ้างอิงเท่านั้น ไม่สามารถใช้ทำนายผลรอบถัดไปได้ เนื่องจากทุกรอบเป็นการสุ่มอิสระ ประวัติการเดิมพันของฉัน แสดงรายการที่ผู้เล่นเดิมพันไปแล้ว พร้อมผลแพ้/ชนะและยอดได้เสียของแต่ละรอบ

    ระบบตรวจสอบความยุติธรรม (Provably Fair)

    เกมนี้ใช้ระบบพิสูจน์ความยุติธรรมที่ผู้เล่นตรวจสอบได้ด้วยตนเอง เพื่อยืนยันว่าไม่มีการกำหนดผลล่วงหน้าเพื่อเอาเปรียบผู้เล่น ก่อนวางเดิมพันทุกรอบ ระบบจะสร้างผลลัพธ์ไว้ล่วงหน้าและประกาศเป็นรหัสแฮช (Early Announced Hash) ให้ผู้เล่นเห็นทันที ค่านี้ไม่สามารถเปลี่ยนแปลงได้อีกหลังประกาศ เมื่อจบรอบ ระบบจะเปิดเผยคีย์ต้นทาง (Private Key / Server Seed) ที่ใช้สร้างผลลัพธ์ สามารถดูข้อมูลนี้ได้ที่พาเนล “Private Key” ด้านบนของหน้าเกมทุกรอบ
